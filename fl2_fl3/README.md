# FL2/FL3

把 FL2 / FL3 两套外观接到 A6700 2.00 的成像链上。改三处：应用层的模式映射、CP 的模式数据、两块色彩参数单元。落点与窗口内指令见 [FL23_DETAILS_2026-10-25.md](FL23_DETAILS_2026-10-25.md)，delta 工具在 [delta/](delta/)，清头工具在 [../wbi/](../wbi/)。

## 三处改动

| 层 | 载体 | 载体大小 | 改动量 | 生效 |
|---|---|---:|---:|---|
| A 应用层映射 | `/usr/lib/appFw.so` | 89,027,992 B | 112 B | 冷启动 |
| B 模式数据 | `/cp/cpapp-b.bin` | 17,892,024 B | 33 窗口，9,536 B delta（实际 4,456 B） | 完整断电 |
| C 色彩参数单元 | `0x02A40001` / `0x02A4000D` | 8,192 B / 28,672 B | 911 B（71 + 840） | 下次启动 |

## 应用层映射

`0x34E5604` 起 112 字节，把菜单里选中的外观和基础样式翻译成一个字节的模式号交给 CP。原厂索引表 10 项，只认 0–9；补丁保留原表，另加两条：基础样式为 ST 且选中自定义 5/6 时，分别输出 19 和 20。

只改转换逻辑不改能力位，菜单不出现；只改能力位不改逻辑，菜单出现但选不中。

写入前后各做一次整文件 SHA-256，窗口内的 112 字节单独比对。

## 模式数据

CP 的初始化数据里给 19/20 各准备一组模式数据：曲线行、Gamma、表指针。改法是原地替换 33 个窗口，每个窗口带 before/after 字节。

模式数据有两份：可选模式表（能不能切过去）和当前模式数据（切过去用什么）。两份不一致时，表现为切了没反应，或者刚切有效、冷启动又回去。

这层必须完整断电才加载。热重启读到的是旧内容。

## 色彩参数单元

`0x02A40001` 存色度（每条 64 字节），`0x02A4000D` 存矩阵（每条 576 字节）。FL2/FL3 用参数 55/56，落在色度槽 23、矩阵槽 25。

目标槽必须是空的，且没有被别的参数引用。否则会出现改了 A 槽、B 槽还在读旧数据。

单元是运行时内存，写入后要关机断电（USB 也不能连着）再开机，相机才会把它写进 `/setting/BACKUP.BIN`。

## 顺序

C → B → A。

C 只写设置数据，回退最省事；B 是区间替换，有明确的 before/after；A 在启动关键路径上，改错主程序就起不来。

每层做完单独验证再进下一层。色调、菜单或模式号不对时，三层是三种不同现象，连着做只能靠猜。

## 验证

| 层 | 做法 |
|---|---|
| C | 写前写后各读一次单元，差异只在预期区间；写完读回 |
| B | 记录整文件指纹，改完读回；冷启动后再读一次 |
| A | 整文件 SHA 对不对；冷启动时先清掉运行时补丁，确认结果来自文件 |

成像对照：固定机位、同曝光与白平衡，拍一组 ST 与目标外观，做 12 段色相和色调斜率的量化比较。

已跑过的量：离线分支验证 525 组 × 3 轮，独立实现交叉核对 19 项，实机对照 6 张，冷启动 ≥3 次，每层回滚演练 1 次。

## 预期行为

- 菜单文字和图标不变。成像链和资源管线是两套。
- B 层热重启不生效。必须断电。
- 第一次冷启动还在、第二次开机消失。多半是两份模式数据不一致，不是写入失败。

## 规模

| 结构 | 规模 |
|---|---:|
| 风格枚举 | 每族 16 槽 |
| 内建外观 | 10 个 |
| look 记录 | 160 B/条 |
| CP 模式 | 42 项，实际启用 2 项 |
| 模式数据窗口 | 33 个 |
| 每槽色彩参数 | 8 项（对比度、高光、阴影、褪色、饱和度、锐度、范围、清晰度） |

空槽占掉就没有了，后续再移植别的风格要另找位置。

## 回滚

C 回写单元备份；B 整段回写备份，回滚后同样要断电；A 回写原始代码，写坏起不来就只能用官方恢复包。

回滚顺序与写入相反（A → B → C），前提是主程序还起得来。回滚后完整断电冷启动，重新核对整文件指纹。

## 风险

| 层 | 写坏之后 | 恢复 |
|---|---|---|
| C | 成像异常，菜单可能报错 | 回写备份 |
| B | 成像异常或起不来 | 回写备份，必要时官方恢复包 |
| A | 主程序起不来，运行时通道一起失效 | 只有官方恢复包 |

## 注意

- 界面没变不等于功能没生效，成像参数和菜单资源是两条线。
- 选项可选只说明能够选，参数重算和状态广播是另一段。
- 热重启后状态还在，不等于已经落盘。
- 窗口校验要整段读回，只比首字节会漏掉局部翻转。
- 不同固件版本结构不同，偏移不能直接照搬。
- AP 与 CP 的版本会各自漂移，回滚状态分开记。
