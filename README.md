# FireHydrant

A6700 固件研究笔记。

记录研究过程中形成的判断与方法：如何确认某项能力是否已存在于固件中、如何区分“界面未呈现”与“功能未生效”、如何在不可逆写入之前用可恢复的方式验证行为。内容停留在方法层面，不包含具体实施数据。

## 目录

- [`DEVICE_CHANNEL.md`](DEVICE_CHANNEL.md) —— 设备通道机制：主机与相机的通信建立、模块加载方式、固件内存的定位与访问，以及运行时修改的可恢复性来源。
- [`fl2_fl3/`](fl2_fl3/) —— 移植类改动的拆解方法：分层验证、常见误判、回退设计。

## 说明

- 本仓库为文字记录，不包含固件二进制、补丁数据与可执行脚本；
- 结论基于 ILCE-6700 固件 2.00 的个人实验，不同版本可能存在差异；
- 内容与厂商无关，不构成操作建议。
