# Cine EI 运行期补丁

A6700 2.00。只改当前 AP 进程的内存，不改 `/usr/lib/appFw.so`，不写 CP，不写 flash。断电或拔电池后恢复原厂。

用途是在写文件之前确认菜单、Base ISO / 曝光指数面板和 HIGH 档的行为。写文件是另一件事，见 [../README.md](../README.md) 和 [../docs/](../docs/)。

偏移只在 A6700 2.00 上成立。这里只列流程、落点和替换字，不包含可直接运行的模块、完整补丁表、代码岛或主机传输。

## Step

| Step | 内容 | 主要落点 | 备注 |
|---|---|---|---|
| 0 | Base ISO / EI 入口、底栏 EI 文字、99 段 UI 窗口 | UI 描述符、显示位 | 可选；Step 2 需要它 |
| 1 | Log shooting 四项可选 | 值节点能力列、可用字节、项目状态 | 不调用 setter，不写 flash |
| 2 | Base ISO / EI 面板解除禁止 | 7 个支持标志、114 对计数/限制 | 只动 Cine EI 相关项 |
| 3 | HIGH 基准 12800 → 2500 | `0x8D915E8`、`0x8D915EC` | 两份必须一致 |
| 4 | 标题读取 Base 阶梯 | `0x2A02CE4`、`0x2A02D6C`、`0x2C55DDC`、`0x2C55E64` | 4 个 4 B 字 |
| 5 | EI 范围、HIGH 重载、派生值 | 5 个代码站点 + 27 条数据记录 | 依赖 Step 2 |
| 6 | 普通 ISO 波轮映射 EI | `0x223A618` | 1 个 4 B 字 |
| 7 | LV 底部 ISO 数值条进 EI | `0x292CBA0`、`0x19DB9D4`、`0x292CAA4` + 80 B 岛 | 可选；实验 |
| 8 | 普通 ISO / AUTO 请求改 Base | `0x3304D0C`、`0x3300D44` + 560 B 岛 | 实验；不依赖 Step 7 |

## 依赖

```text
Step 0 ──> Step 1 ──> Step 2 ──> Step 3 ──> Step 5 ──> Step 6
                         │                    │
                         └──> Step 4 ─────────┘
                                              ├──> Step 7
                                              └──> Step 8
```

Step 4 不依赖 Step 3。Step 6/7/8 依赖 Step 5 的合法范围。Step 7 和 Step 8 互不依赖。

## 地址

运行地址 = AP 基址 + ELF VA。`lib_appFw.so` 是 AArch64 `ET_DYN`，基址每次启动不同，所以文档只写 ELF VA，不写某次运行看到的 `0x7f...`。

插入前核对整份 AP 指纹。只支持原厂 stock 或已经验证的 FL23 基线。V3 固化版不适用。

## 写入

1. 只读 AP 映射，核对指纹、ELF VA、目标页权限和 20 B 邻域。
2. 目标在 RX 段时，临时把所在页改为可写。
3. 4 B 字用原子写；数据字段按 u32/u8 写。
4. 刷 D-cache / I-cache。
5. 读回校验。
6. 恢复页权限。
7. 记录当前 boot/PID 的撤销快照。

任何一步读到非预期值就停止。运行期补丁一般不改 ELF 程序头。

## 检查

| 位置 | 结果 |
|---|---|
| Log shooting | 四项齐全，Cine EI Quick / Cine EI 可选，选中后不重启、不报错 |
| Base ISO | LOW/HIGH 能切，画面曝光档位跟着变 |
| 曝光指数 | 能改值，不显示 `—`，不残留上一个值的格式片段 |
| HIGH | 640/1600/2500/3200 可选，不黑屏；Quick 阈值附近不断档 |
| 标题 | Base 800 → `N=800`；Base 2500 → `N=2500` |
| 一致性 | 反复切 Base，范围连续，HIGH 基准不回 26，E 格式连续 |
| 波轮 | 普通 ISO 波轮改变 EI |
| 触屏 | 点 LV 底部 ISO 打开 EI 数值条 |
| Base 请求 | 普通 ISO=AUTO 不影响实时取景曝光 |

`RESULT=APPLY_OK` 只说明写入完成，不说明功能生效。功能以菜单现象和实拍为准。

## 回滚

- 单个 Step 用 `--undo`，只恢复它自己的代码/数据字。
- 组合撤销按反序：Step 8 → 7 → 6 → 5 → 4 → 3 → 2 → 1 → 0。
- Step 3/5 撤销时保持 Cine EI + Base LOW，停止录制。
- Step 1 没有 `--undo`，断电恢复。
- 完整断电 10 秒，所有 RAM 补丁消失。
- 跨 boot 的旧快照只归档或移除，不把旧 RAM 恢复到新进程。
- 在菜单里选中 Cine EI 会走原厂 setter，把 Log 值写进 flash。这不是运行期补丁，回滚要单独处理。

运行期改动会覆盖文件层状态。验证文件前先断电。

## 限制

- 只支持 A6700 2.00。
- 不同固件/机型的地址、PID、结构会变。
- Step 7 的拖动/关闭行为、Step 8 的 CP 侧曝光链还没闭合。
- 黑屏不一定由 HIGH 基准造成；基准只保证计算范围一致。
- EVF / HDMI 的 EI 显示是布局作用范围限制，不是渲染缺陷。
- 菜单文字、图标和功能是三套东西。
