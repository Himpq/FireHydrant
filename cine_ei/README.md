# Cine EI / Cine EI Quick

A6700 2.00 的拍摄链里有 Cine EI，只是没接到菜单上：Log shooting 只列 Off 和 Flexible ISO，Base ISO 与曝光指数面板被支持计数挡住，HIGH 档按 12800 算。这个目录记三处的改法、验证方式和固化包。

落点、段数、hook 见 [docs/CINEEI_PATCH_DETAILS_2026-10-25.md](docs/CINEEI_PATCH_DETAILS_2026-10-25.md)。

## 现状

- `set_log_shooting` 本身不拦 2/3 两个值，写进去能持久化，重启还在。
- 菜单里看不到这两项：Log shooting 行的能力列没放行，可用字节是关闭状态。
- 能选之后，Base ISO 与曝光指数面板仍被一组支持计数判为不支持，选 EI 会显示 `—`。
- HIGH 档的菜单范围是 640–10000，计算却锚在 12800；640、1600、2500 会无效、暗屏或黑屏。

## 三处改动

### 菜单选项

Log shooting 行的能力列、可用性字节、项目状态。改完菜单出现四项：Off、Flexible ISO、Cine EI Quick、Cine EI，两项可选。

只放行能力列不够，可用字节和项目状态要一起改，否则选项会显示成灰色。

### Base ISO / 曝光指数面板

一组支持标志，加上成对的禁止计数与限制字节，约 114 对。只解除 Cine EI 需要的那些计数，其它拍摄模式留下的限制不动。

计数是成对的，改单边会让别的模式条件跟着变。

### HIGH 档基准

两份 HIGH 基准副本，内容必须一致。改完 HIGH 从 12800 对齐到 2500，菜单范围与计算范围重合。

两份不一致时，菜单能选、计算仍按旧基准，表现是选值无效或黑屏。

## 顺序

按菜单、面板、基准的次序做，每步单独验证。

EI 显示不对时，三层是三种不同的现象：菜单没有说明第一层没成；能选但面板显示 `—` 说明第二层没成；面板能开但 HIGH 档黑屏说明第三层没成。三层连着做，就只能猜。

## 验证

| 位置 | 看什么 |
|---|---|
| Log shooting | 四项齐全，两个新项可选中，选中后不重启、不报错 |
| Base ISO | LOW/HIGH 能切，切换后画面曝光档位跟着变 |
| 曝光指数 | 能改值，不显示 `—`，不残留上一个值的格式片段 |
| HIGH 档 | 640/1600/2500/3200 可选，选中不黑屏 |
| Quick 阈值 | 1600 附近不断档，1600/2000/2500 连续 |

菜单文字出现但选不中，说明能力列或可用计数没改完。文字、图标与实际功能是三套东西，功能生效而文字没变是正常的。

## 数据量

| 项 | 规模 |
|---|---:|
| Log shooting 选项 | 4 项（新增 2 项） |
| 支持标志 | 约 7 个 |
| 禁止计数/限制字节 | 约 114 对 |
| HIGH 基准副本 | 2 份 |
| Base 档位 | 2 档（LOW/HIGH） |
| EI 阶梯 | 约 26 档（160 起，菜单只开放一段） |

## 运行期与固化

实验阶段是运行期改动，只改当前开机内的状态，断电回原厂。通过菜单选中 Cine EI 之后，Log 值由原厂 setter 写进 flash，这部分不算在补丁里，回滚要单独处理。

固化版把字节写进 `/usr/lib/appFw.so`，往 RX 段尾部追加代码并改程序头，所以还要先把 WBI 快照头清成 512 字节零，否则冷启动仍按旧段布局加载。

回退分两级：先反向写 827 字节回 FL23 基线，再写回 512 字节头，断电。

## 回滚

顺序与写入相反：基准、面板、菜单。

回滚后完整断电冷启动，再逐项核对。运行期补丁会盖住文件层的真实状态，验证持久化之前先断电。

## 注意

- 菜单可见不等于面板可用，两处是独立计数。
- HIGH 基准是计算锚点，不是当前 EI 值，两者不能混写。
- `—` 是无效哨兵，残留的 `E` 是格式参数没刷新，处理方式不同。
- 黑屏不一定来自基准，基准只保证范围一致。
- 同一机型不同固件版本，内部结构可能不同。
- EVF 与 HDMI 输出的 EI 显示不一定跟随机背屏。
